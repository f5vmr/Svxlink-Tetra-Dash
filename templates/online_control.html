Emergency DTMF Control

Allow authorised operators to take a radio logic offline and return it online using a private command.

This feature is optional. Choose a private six-digit command and share it only with authorised operators. Settings apply separately to each radio logic.

Operating instructions

Enter your six-digit command followed by 0# to take the logic offline, or 1# to return it online.

Prefix the complete command with * if a module is active.

The generated configuration starts the logic online. Saving these settings requires a configuration rebuild before they take effect.
