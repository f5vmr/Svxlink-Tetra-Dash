Installation and certificate identity

The certificate request and reflector connection will use {{ primary_callsign }} as the installation callsign.

Changing this callsign after certification may generate a new certificate request requiring approval by the reflector administrator.

The reflector administrator should provide the hostname or IP address and port. The reflector server certificate must identify that same hostname or IP address. A mismatch cannot be corrected in this client configuration.
On the first connection, SvxLink generates a private key and certificate signing request. The reflector administrator reviews and approves that request. Access may initially be denied while the request is awaiting approval.

Talkgroup configuration

Default and monitored talkgroups are configured later from the main dashboard Talkgroups page. They are not required to establish the initial reflector connection.

The initial configuration uses a default talkgroup of 0 and no monitored talkgroups. These settings can be changed after the installation has been built.
