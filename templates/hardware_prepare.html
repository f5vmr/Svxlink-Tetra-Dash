This hardware profile requires preparation before normal configuration can continue.

{% if profile.family == "ics" or profile.type == "port_based" %}
Some hardware profiles, especially ICS boards, require staged preparation. This may include enabling I2C, applying a board-specific overlay, checking extended GPIO, and rebooting before the dashboard can continue safely.
An ICS 1X board appears in this preparation route even though it has only one port, because it still requires the same ICS hardware setup process.
{% elif profile.type == "multi_interface" %}
This multi-interface USB profile verifies two duplex USB audio devices and two C-Media HIDRAW interfaces before normal configuration can continue.
The two duplex USB audio devices are assigned to Port 1 and Port 2 in their detected order. Their named ALSA identifiers are stored so unrelated host sound hardware does not change the SvxLink audio configuration. The corresponding C-Media HIDRAW devices are assigned alongside them. Leave both radio interfaces connected to their present physical USB sockets.
PTT and COS may later be selected per port as HIDRAW, GPIOD or serial. HIDRAW verification on this page does not require HIDRAW to be selected as the final control method.
