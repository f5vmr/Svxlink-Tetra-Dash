Installation Identity

Select the primary radio port whose callsign identifies this installation as a whole.

The primary callsign is used for ReflectorLogic, node information, the dashboard installation identity and the system login display. Secondary ports may use the same callsign or different callsigns.

Primary port and reflector operation

If reflector operation is enabled, the primary port must be included in the reflector link. Additional ports may also be connected to that reflector.

The primary selection does not prevent this port from being independent or participating in a local link when reflector operation is disabled.
