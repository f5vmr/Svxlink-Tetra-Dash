Node Type

Choose the type of SvxLink station you are building.
A simplex node is a standalone station that transmits and receives on the same frequency,
while a repeater node is connected to a radio transmitter and receiver and can be used with a
duplexer to operate on separate transmit and receive frequencies.

The node type can be changed later if needed, but the callsign cannot be changed after this step.

A TETRA node connects one TETRA radio through USB audio, a PEI serial connection and separate wired PTT. The radio's TETRA operating mode is selected on the next page.

Audio Response
Audio emphasis guidance

Leave pre-emphasis and de-emphasis disabled unless the radio interface uses a flat or discriminator-level audio path that specifically requires them.

Applying de-emphasis to audio that has already been de-emphasised by the radio may prevent reliable DTMF decoding.

Enable these SvxLink audio filters when required by the radio audio path, particularly when using flat or discriminator audio.
